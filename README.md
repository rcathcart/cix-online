# CIX Online

A two-player web page for demonstrating CIX card games. Live at https://rcathcart.github.io/cix-online/

Current game: CIX Zoo. The host picks a zoo, season and play mode and deals one shared day; each player plays their own day on their own row and watches the other's. Players connect peer to peer with PeerJS using a short room code. No accounts, no server.

Card data in `index.html` is a copy of the Zoo Exhibit Cards database in Notion; update both together.
